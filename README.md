# 宏逸科技資訊 應收帳款

RWD 上傳頁 + 後台，資料庫用 Google 試算表 + Apps Script（跟咖啡進貨、業務日報表同一模式）。

## 網址（部署後填）
- 上傳頁：`https://wengming-jimmy.github.io/hongyi-receivables/`（內部用，勿公開）
- 後台：同網址加 `admin.html`（公開頁無連結，首次開啟需自設密碼，本機簡易鎖，勿公開）
- 試算表：「宏逸科技應收帳款」，分頁「應收明細」17 欄（上傳時間、報價單號、大項、項次、日期、客戶、描述、單價、數量、應收帳款、報價總額、狀態、收款方式、收款日期、收款人、收款備註、來源檔名）
- Apps Script：`Code.gs`（本機留存，不要推上公開庫），部署為網路應用程式後把 `/exec` 網址寫進 `config.js`

## 怎麼用
1. 上傳頁選報價單 Excel（.xls / .xlsx），先看解析結果：報價單號、日期、客戶、品項、含稅總計、品項合計是否一致，確認才按寫入。
2. 後台清單只顯示大項、項次、日期、客戶、應收帳款、狀態；點「詳細」才展開描述全文、單價×數量、報價總額。
3. 詳細裡改狀態：應收／已收／結案。選「已收」一定要選收款方式（現金／匯款／其他）、填收款日期、收款人；也可以按「整張報價單一起改」把同一張號碼的每一筆一起改。
4. 改回「應收」會清空收款欄位；改成「結案」會保留收款資料。
5. 同一報價單號重複上傳會先提醒，確認覆蓋才會刪舊寫新，避免重複。

## 報價單格式（已用 Q202604071553.xls 驗證）
- 客戶：客戶名稱那一格；日期：Date 那一格；報價單號：NO 那一格
- 表頭 Prod.# / Description / 單價 / Q'TY / AMOUNT，往下讀到「小計／含稅總計」停
- 大項 = Prod.#（例如主機、螢幕、服務），一列 = 一個品項，逐筆寫入
- 範例檔解析結果：2026/04/07、3 筆、含稅總計 NT$8,000（主機 5,000＋螢幕 1,000＋服務 2,000）
- 未來格式變動（欄位移位、新增欄位）要先調解析規則再上傳
